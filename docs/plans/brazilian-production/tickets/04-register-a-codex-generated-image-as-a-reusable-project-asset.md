## What to build

An image produced in Codex becomes a formal ArcReel character or scene asset and a storyboard image through existing upload paths, ready for supported downstream generation.

## Acceptance criteria

- [ ] Exercise existing authenticated uploads for one reusable asset and one storyboard; preserve formal registration, version history and currency.
- [ ] Confirm downstream request preview resolves the selected image and correct asset identity; copying files alone does not satisfy ingestion.
- [ ] Use existing transport where possible; add only a narrow wrapper if required for a reproducible Codex handoff.
- [ ] Record whether the local image handoff is practical; preserve the agreed Nano Banana 2 fallback without a new asset store.
- [ ] Any image-generation call uses the applicable approved usage policy; no paid provider request without an explicit allowance.

## Blocked by

None (can start immediately).
