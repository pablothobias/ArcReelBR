## What to build

A project explicitly configured for Brazilian Portuguese retains Portuguese dialogue, narration and subtitles while generating English technical directions and leaving the interface in English.

## Acceptance criteria

- [ ] Accept and consistently normalize an explicit Brazilian Portuguese content language through relevant project/tool/schema paths.
- [ ] Use suitable Portuguese reading units and configurable speech-rate behavior rather than the Chinese unknown-language fallback.
- [ ] Separate technical prompt prose from literal spoken content in the existing supported generation routes.
- [ ] Verify create/edit/read and representative drama, narration and reference-video prompt paths; existing languages and projects retain compatibility.
- [ ] Demonstrate a source-to-structured-content example with English instructions and unchanged intended Portuguese speech using deterministic fixtures.

## Blocked by

None (can start immediately).
