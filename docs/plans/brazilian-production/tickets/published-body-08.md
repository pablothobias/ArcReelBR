## What to build

Codex receives sufficient evidence from an accessible video and its reference to evaluate visuals, Portuguese speech, continuity and subtitle timing, producing actionable per-segment review results.

## Acceptance criteria

- [ ] Reuse existing image/contact-sheet and local technical-signal tools; demonstrate access to actual audio and video beyond sampled still images.
- [ ] Verify audio/transcription or equivalent inspection capabilities rather than assuming an evaluator exists; use only necessary thin integration.
- [ ] Compare spoken content and timing to the intended script and reference goals; distinguish missing evidence from passing results.
- [ ] Exercise known-good and intentionally defective fixtures covering wrong/missing speech, identity/story errors and visibly mistimed subtitles.
- [ ] Emit evidence-linked corrections using existing script/timeline operations where supported; identify any unsupported required correction precisely.
- [ ] Preserve the existing subtitle/rendering pipeline; do not build a speculative second system or claim frame sampling proves lip-sync.
- [ ] New metered evaluation services require a concrete quote and authorized allowance before use.
