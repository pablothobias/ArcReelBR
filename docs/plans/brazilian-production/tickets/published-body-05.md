## What to build

Codex selects a representative request from the owner's 30-item collection, verifies its foreign reference, improves its Brazilian adaptation and delegates ingestion into an existing formal episode.

## Acceptance criteria

- [ ] Read actual reference content and record source identity, access date and observed events; titles/descriptions alone are insufficient.
- [ ] Find a verified compatible replacement when needed; if none is accessible pause that item rather than invent reference details.
- [ ] Preserve the original request and record changes to dialogue, duration and narrative decisions under the approved autonomy.
- [ ] Map source text and montage intentions to existing structured planning/review contracts; register assets and confirm the formal script through supported operations.
- [ ] Remove dependence on inherited unspecified budgets; distinguish montage timing from model generation durations.
- [ ] Demonstrate a formal episode with Portuguese content, English technical prompts and reusable existing project assets, without paid media generation.
