## Objective

Make the existing local ArcReel workflow usable end to end for reference-led Brazilian social videos, preserving the harness. Codex owns research, adaptation, supervision, budgets and review; the embedded Agent executes production. Use the existing 30-request collection as input, start with one pilot, then validate existing series continuity before bounded batches.

## Accepted constraints

- Internal text: official Claude Agent SDK with the owner's subscription login, Opus 5.5, medium effort; no automatic paid API fallback.
- Creative content is Brazilian Portuguese; technical prompts and interface are English.
- Video: official international MiniMax H3. Images: Codex-produced assets via supported uploads when practical, otherwise existing Nano Banana 2 integration. Test native audio first; ElevenLabs remains a conditional alternative.
- Deliver vertical 1080 × 1920 with Portuguese burned subtitles, title, description and source information; no automatic social publication. Verify native model tiers separately from final resolution.
- Budget and attempt policy is implemented in Codex context, not ArcReel backend enforcement. Numeric ceilings require owner approval after a concrete quote. Start with one pilot; unknown costs pause. At most two quality regenerations after the initial generation per rejected segment.
- Automate while Codex and the local application run; preserve checkpoints for explicit resumption, without a new unattended supervisor.
- Reuse existing MCP, session service, source/script contracts, assets, episode ledger, quotes, accounting, recovery, editing and exports.

## Completion evidence

A reviewed real pilot, bounded cost record, tested recovery, actual audio/video inspection, a separate two-episode continuity sample, and readiness status for remaining requests. Existing mocked tests or generated text claiming success are insufficient.

## Conditional follow-ups

Create separate actionable work only when the native pilot exposes a concrete unmet requirement: ElevenLabs integration and model/voice choice, lip-sync, or subtitle alignment. Do not preemptively implement these or falsely pass a failing pilot.
