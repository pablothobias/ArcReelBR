## Explicit preservation qualifications from the expanded pass

- Snapshot=False refreshes the full append prompt, including user memory on reconnection; it can affect prefix caching/tokens/fingerprints, as ADR 0122 records. Per-message language context also modifies SDK message delivery. Preserve the approved language objective without claiming these are cosmetic or model-equivalent changes.
- Internal subscription text selects a constrained, separate SDK call with fixed model/effort and no tools/MCP/skills/session persistence; quota signaling stops automatic retry without proving durable automatic resumption. Preserve the native backend seam and no-paid-fallback contract.
- Applied measured timing is reloaded in ordinary presentation reads and downstream renders; removing the compulsory ASR instruction does not discard previously applied timing. Preserve provenance and invalidation.
- Gemini changes include non-idempotent retry handling, retained failure usage and catalog-derived output token limits, not just MIME fixes. Preserve these native safeguards; provider output is not certified identical.
- Current external host setup/credentials remain the parallel configuration scope. R12 is a code-level mismatch, independently reproduced with synthetic flags, rather than a claim about the user's current running environment.
