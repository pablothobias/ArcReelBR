# RafaCena interface foundations

The RafaCena identity uses the approved R film-frame symbol and horizontal wordmark in `public/rafacena-logo.png`, with optimized derivatives for display, browser icons, and installed-app icons. The original image is a raster with a cream background; it is not a transparent or scalable logo master. Custom `VITE_BRAND_NAME` values retain their text label beside the symbol.

The semantic color, font, radius and motion tokens live in `src/index.css`. Light mode follows the RafaCena palette: teal `#087F73`, orange `#F26B3A`, cream `#FAF6EF`, ink `#17242B` and white surfaces. Dark mode uses accessible lighter teal and text on dark green-gray surfaces. Use semantic Tailwind utilities instead of embedding values in components. The orange accent is decorative, not a white-text button background.

Nunito Sans is bundled locally for interface text, with system fallbacks for scripts it does not contain. Spacing uses Tailwind's four-pixel base; controls use 10px corners, cards 16px and larger surfaces 24px. Default buttons, fields and select controls are 44px high. Explicit compact variants remain available for dense editing tools. Keep labels, keyboard focus, error messages and non-color status cues in each control's composition. Episode production uses the approved orange accent while completed episodes use teal; the lobby also reports both counts in text. The existing project and editor layouts retain their workflows and responsive behavior.

This visual rebrand does not change language support, backend protocol names, existing project data or upstream marketplace identities. The optimized WebP preserves the artwork while reducing its dimensions for display, and the original PNG remains the fallback. Browser and installed-app icons include square PNGs and maskable variants derived from the approved symbol. A true vector master can replace these raster derivatives when available; installed-app presentation still requires device verification.
